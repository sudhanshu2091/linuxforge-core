# LinuxForge Core V50.4 — Mission V2 foundation

## Included

- Topic-first mission navigation.
- Explicit `Levels` and `Infinity` modes inside every topic.
- Fixed 1–50 level map per topic.
- Existing deterministic mission contracts remain the source of truth for published executable levels.
- Unpublished level slots are visible but are never presented as executable missions; this prevents the UI from inventing verifier coverage that does not exist yet.
- Infinity generation is topic-aware and continues to use the existing generated-exercise validation, novelty gate, terminal workflow and deterministic verifier.
- Level, mastery and difficulty remain separate concepts.
- Existing real-Kali terminal/runtime architecture is preserved.
- QEMU quarantine recovery and detached-stdin robustness fixes are retained in this package.

## Important boundary

This release deliberately does not pretend that all 50 levels for every topic already have production-grade executable contracts. The curriculum surface is now capable of representing all 50 levels, while only contracts that the current verifier can actually prove are published. The next curriculum slices can add real contracts without changing the progression architecture.

Networking, package installation and broader VM capabilities remain separate runtime/security work. They should not be simulated by the mission UI.
