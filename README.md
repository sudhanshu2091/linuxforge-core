# LinuxForge Core

Build the first-stage UI foundation for LinuxForge AI, a premium desktop-first AI-powered cybersecurity and Linux learning platform. Before implementation, briefly state these architectural assumptions in the project response: frontend-first reusable component/page-shell architecture; auth, learner data, AI/n8n orchestration, and sandboxed terminal are future integration boundaries; no fake backend or live terminal/hacking functionality. Then implement only: landing page, global navigation, authentication screens, dashboard shell, profile shell, learning page shell, challenge page shell, AI tutor shell, terminal page shell, progress page shell, achievements page shell, friends page shell, and settings page shell. Make it polished, modern, responsive, developer-tool/cybersecurity/game-progression inspired, not a generic LMS. Use reusable components and clearly indicate nonfunctional future-connected areas. The AI tutor UI should convey a friendly senior mentor and include natural Hinglish-ready language controls, but no actual AI. Do not expose n8n or implement it. Do not implement backend functionality, real-machine terminal access, or unrestricted hacking capabilities.
